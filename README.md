# 借你一个下午

把私人城市路线写成一封可以走进去的信。作者选择 2–6 个地点，留下文字、照片或录音；读者逐站阅读或步行探索，最后给作者留下回信。

这是百度地图开发者创作大赛的参赛预览项目。仓库提供前端、Node.js 服务、测试与现成演示素材；公开仓库本身不代表已部署可用的在线服务。

## 演示素材

- [54 秒无声演示视频](public/demo.mp4)：实际页面截图组成，展示地点确认、逐站阅读和回信流程。
- [演示说明页面源码](public/review.html)：启动服务后访问 `/review.html`。

## 本地运行

需要 **Node.js 22 或更高版本**。当前代码仅使用 Node.js 内置模块，无须安装第三方 npm 依赖。

```sh
npm start
```

打开 <http://localhost:8793>。默认仅监听本机。未配置地图凭据时，可浏览示例及其已有路线快照；新的地点检索和 Agent Plan 步行查询需要服务端凭据。

### 百度地图依赖

在自己的服务端运行环境中设置 `BAIDU_MAP_AUTH_TOKEN`，连接百度地图 Agent Plan 的 Place / Direction 能力。不要把真实值写进源码、README、提交记录或浏览器端代码。

可选浏览器地图使用百度地图 JSAPI 4.0 的浏览器端 AK，并需要对应域名白名单。浏览器端 AK 可在界面中配置，或由 `BAIDU_MAP_AK` 提供；它会传给前端，**不能放服务端秘密凭据**。未配置浏览器地图时，保留独立地图入口与文字路线信息。

配置与接口说明以[百度地图开放平台](https://lbsyun.baidu.com/)为准。新的地图请求需要网络和自己的可用额度；页面字体还会请求 Google Fonts，网络不可达时使用本地后备字体。

| 环境变量 | 用途 / 默认值 |
| --- | --- |
| `BAIDU_MAP_AUTH_TOKEN` | 服务端 Agent Plan 凭据；仓库不提供 |
| `HOST` / `PORT` | 监听地址与端口；`127.0.0.1` / `8793` |
| `DATA_DIR` | 服务数据目录；项目下 `.data/` |
| `PUBLIC_ORIGIN` | 已部署服务的公开访问地址；留空时按本地使用处理 |
| `MAP_DAILY_LIMIT` | 每日新增地图查询上限；默认 100 |

如自行部署，需要运行 Node.js 服务和可持久写入的数据目录，不能只把静态文件放到 GitHub Pages。仓库附有 Dockerfile，但本次未部署或验证 Docker 运行。

## 数据与限制

- 草稿及作者查看回信的凭据保存在当前浏览器；清除浏览器数据可能失去查看权限。
- 生成的路线、附件和回信写入服务的数据目录。路线可通过持有链接访问；查看回信需要作者凭据。请只使用适合演示的非敏感内容。
- 地点查询和规划参数发给百度地图；故事、照片、录音和回信不作为地图请求参数发送。
- 当前是参赛预览，尚未完成真实用户需求验证、实地走访、手机麦克风/GPS 验收。地图底图效果受浏览器 AK、域名配置及网络影响。
- 本仓库没有依赖某个私人后端地址；需在自己的环境运行随附服务。旧临时演示域名未作为可用入口发布。

## 本地测试

```sh
npm test
```

测试覆盖输入校验、路线创建与持久化、作者回信访问控制、地图响应归一化、缓存/额度以及界面地图逻辑。地图测试使用模拟响应和已保存的公共地点数据，不验证在线百度服务、手机硬件权限或公开部署效果。测试会创建临时数据并短暂启动本地 HTTP 服务。
